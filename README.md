# Эмулятор оболочки ОС (Вариант 17)

## Описание
GUI-эмулятор командной оболочки UNIX-подобной ОС.

## Этап 1. REPL
Минимальный прототип с графическим интерфейсом.

### Возможности
- Заголовок окна формируется на основе реальных данных ОС: `Эмулятор - [username@hostname]`
- Простой парсер команд (разделение по пробелам)
- Команды-заглушки: `ls`, `cd`
- Команда `exit`
- Обработка неизвестных команд

### Запуск
```bat
run.bat
