# Эмулятор командной строки UNIX-подобной ОС

## Общая информация
- **Дисциплина:** Конфигурационное управление
- **Вариант:** 17
- **Язык реализации:** Python 3
- **Интерфейс:** Графический (GUI на базе tkinter)

## Описание этапов реализации

### Этап 1. REPL и графический интерфейс
Реализован минимальный прототип с графическим интерфейсом. Окно содержит область вывода (стилизована под терминал) и поле ввода. Заголовок окна формируется на основе реальных данных ОС в формате `Эмулятор - [username@hostname]`. Реализован простой парсер ввода, разделяющий строку на команду и аргументы по пробелам. Добавлены команды-заглушки `ls`, `cd` и команда завершения `exit`. Реализована обработка ошибок: неизвестная команда и незакрытые кавычки.

### Этап 2. Конфигурация и стартовые скрипты
Добавлена поддержка аргументов командной строки (`--vfs`, `--prompt`, `--script`) через модуль `argparse`. Реализован механизм выполнения стартовых скриптов: команды читаются построчно, при первой ошибке выполнение скрипта останавливается, ввод и вывод имитируют диалог с пользователем. При запуске в консоль выводится отладочная информация о переданных параметрах. Добавлена служебная команда `conf-dump`, выводящая параметры эмулятора в формате ключ=значение.

### Этап 3. Виртуальная файловая система (VFS)
Подключена VFS на основе CSV-файла со столбцами `path`, `type`, `content`. Все операции выполняются строго в памяти. Вложенные элементы представляются полными путями в столбце `path`. Реализована поддержка двоичных данных через кодировку base64. Добавлена обработка ошибок загрузки (файл не найден, неверный формат CSV) с выводом соответствующего сообщения без аварийного завершения программы.

### Этап 4. Основные команды
Реализована полноценная логика навигации и чтения файлов:
- `ls`: вывод отсортированного списка содержимого директории с поддержкой относительных и абсолютных путей
- `cd`: смена текущей директории с разрешением путей
- `tac`: вывод содержимого файла в обратном порядке строк
- `uname`: вывод информации об операционной системе
- `who`: вывод текущего пользователя и имени хоста

## Описание функций модулей

### Класс VFSNode (src/main.py)
- `__init__`: создаёт узел VFS (файл или каталог) с именем, типом и содержимым

### Класс VFS (src/main.py)
- `__init__`: инициализирует корневую директорию VFS
- `load_from_csv`: читает и парсит CSV-файл в дерево узлов в памяти
- `resolve`: возвращает узел по абсолютному или относительному пути относительно текущей директории

### Класс ShellEmulator (src/main.py)
- `__init__`: создаёт окно tkinter, загружает параметры конфигурации и VFS, выводит отладочную информацию
- `write_output`: безопасно добавляет текст в поле вывода, сохраняя его доступным только для чтения
- `parse_command`: разделяет строку ввода на команду и аргументы, проверяет незакрытые кавычки
- `execute`: диспетчеризирует выполнение команды по имени
- `cmd_ls`: реализует логику листинга директории
- `cmd_cd`: реализует логику смены директории
- `cmd_tac`: реализует вывод файла в обратном порядке строк
- `cmd_uname`: выводит информацию об ОС
- `cmd_who`: выводит текущего пользователя и хост
- `on_enter`: обрабатывает ввод пользователя, передаёт данные в парсер и обновляет экран
- `run_startup_script`: читает файл скрипта и последовательно выполняет команды, останавливаясь при первой ошибке
- `run`: запускает главный цикл обработки событий tkinter

## Сборка и запуск

### Требования
- Python 3.8+
- tkinter (входит в стандартную поставку Python)

### Запуск эмулятора
```bat
rem Базовый запуск
run.bat

rem Запуск с загрузкой VFS
run.bat --vfs vfs\deep.csv

rem Запуск с VFS, приглашением и стартовым скриптом
run.bat --vfs vfs\deep.csv --prompt "stage4> " --script scripts\test_stage4.txt
