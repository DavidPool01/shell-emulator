# Эмулятор оболочки ОС (Вариант 17)

## Описание

GUI-эмулятор командной оболочки UNIX-подобной ОС.

## Этап 1. REPL

Минимальный прототип с графическим интерфейсом.

- Заголовок окна на основе реальных данных ОС: `Эмулятор - [username@hostname]`
- Простой парсер: разделение ввода на команду и аргументы по пробелам
- Команды-заглушки `ls`, `cd`, команда `exit`
- Обработка ошибок: неизвестная команда, незакрытые кавычки

## Этап 2. Конфигурация

Поддержка параметров командной строки и стартовых скриптов.

### Параметры запуска

`--vfs` — путь к физическому расположению VFS
`--prompt` — пользовательское приглашение к вводу
`--script` — путь к стартовому скрипту

### Новые возможности

- Отладочный вывод всех параметров при запуске
- Команда `conf-dump` (вывод параметров в формате ключ=значение)
- Стартовый скрипт останавливается при первой ошибке
- Проверка незакрытых кавычек

## Этап 3. VFS

Подключение виртуальной файловой системы. Все операции выполняются в памяти.

### Новые возможности

- Источник VFS — CSV-файл со столбцами `path`, `type`, `content`
- Вложенные элементы представляются полными путями в столбце `path`
- Двоичные данные хранятся в base64
- Сообщение об ошибке загрузки VFS (файл не найден, неверный формат)
- Стартовый скрипт `scripts/test_all.txt` тестирует все команды этапов 1–3

### Файлы VFS

`vfs/minimal.csv` — минимальная VFS
`vfs/multi.csv` — несколько файлов и папок
`vfs/deep.csv` — не менее 3 уровней файлов и папок

## Запуск

```
run.bat
run.bat --vfs vfs\multi.csv --prompt "test> " --script scripts\test1.txt
scripts\run_test1.bat
scripts\run_test2.bat
scripts\run_test3.bat
scripts\run_vfs_minimal.bat
scripts\run_vfs_multi.bat
scripts\run_vfs_deep.bat
scripts\run_vfs_error.bat
```
